# Naming Standard

Use consistent names so lab resources are easy to find, review, and remove.

## Recommended pattern

`az104-<module>-<workload>-<env>-<region>-<sequence>`

## Examples

| Resource | Example |
| --- | --- |
| Resource group | `rg-az104-net-core-dev-eus-001` |
| Virtual network | `vnet-az104-core-dev-eus-001` |
| Storage account | `staz104diagdeveus001` |
| Log Analytics workspace | `log-az104-ops-dev-eus-001` |

## Required tags

| Tag | Example value |
| --- | --- |
| `Project` | `AZ-104 Enterprise Administrator Lab` |
| `Environment` | `Lab` |
| `Owner` | `Kishorebiswajit` |
| `CostCenter` | `Training` |
| `ExpiresOn` | `YYYY-MM-DD` |
