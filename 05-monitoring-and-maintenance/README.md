# 05 - Monitoring and Maintenance

Labs for monitoring, alerting, operational insights, backup, recovery, and update management.

## Folders

| Path | Purpose |
| --- | --- |
| `azure-monitor/` | Metrics, alerts, action groups, and dashboards. |
| `log-analytics/` | Workspaces, diagnostic settings, KQL queries, and insights. |
| `backup-and-recovery/` | Recovery Services vaults, backup policy, restore tests, and recovery evidence. |
| `update-management/` | Update assessment, maintenance configuration, and patching records. |
