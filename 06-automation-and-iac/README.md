# 06 - Automation and IaC

Reusable automation and infrastructure-as-code assets for AZ-104 lab deployments and validations.

## Folders

| Path | Purpose |
| --- | --- |
| `arm-templates/` | ARM templates and parameter files. |
| `bicep/` | Bicep modules, deployments, and parameter files. |
| `terraform/` | Terraform modules and environment examples. |
| `powershell/` | Azure PowerShell deployment and validation scripts. |
| `azure-cli/` | Azure CLI deployment and validation scripts. |
