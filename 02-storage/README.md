# 02 - Storage

Labs for Azure Storage accounts, Blob Storage, Azure Files, access controls, encryption, lifecycle policies, and operational validation.

## Folders

| Path | Purpose |
| --- | --- |
| `blob-storage/` | Containers, access tiers, shared access signatures, and replication. |
| `files/` | Azure Files shares, snapshots, and access configuration. |
| `security/` | Network access, private endpoints, encryption, and identity-based access. |
| `lifecycle-management/` | Lifecycle rules, retention, soft delete, and cost controls. |
