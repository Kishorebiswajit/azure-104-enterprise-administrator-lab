# 01 - Identity and Governance

Labs for Microsoft Entra ID, users and groups, role-based access control, Azure Policy, resource locks, and tagging strategy.

## Folders

| Path | Purpose |
| --- | --- |
| `entra-id/` | Tenant, user, group, and identity administration labs. |
| `rbac/` | Built-in roles, custom roles, assignments, and least-privilege exercises. |
| `policy/` | Policy definitions, assignments, initiatives, remediation, and compliance. |
| `locks-tags/` | Management locks, required tags, and naming governance. |
